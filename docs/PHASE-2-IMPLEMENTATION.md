# Phase 2 implementation

The Phase 2 foundation provides deterministic query normalization/identity, explicit evidence and demand semantics, intent/problem/commercial extraction, lightweight JTBD, verified-destination-only SERP competitors, unknowns, contradictions, opportunity candidates, and next validation actions. It adds a JSON Schema, controlled fixtures (commercial comparison, direct problem, utility, local, informational, ambiguous), and a deterministic sample report at `raw_evidence/phase2/`.

The module preserves Phase 1 boundaries: DataForSEO is unchanged and default; OpenSERP remains experimental; wrapper destinations cannot enter competitor intelligence; no automatic fallback, live request, redirect resolution, or LLM call was introduced.
